# Impuls – pliki znaku

Znak akcji **Impuls · Każdy punkt się liczy** (Misja AED – Dane na ratunek).

## Struktura

```
brand/
  logo/
    svg/   wektor, format otwarty (napisy zamienione na krzywe)
    pdf/   wektor do druku
    png/   raster z przezroczystym tłem (sygnet 1024 px, pozostałe 2400 px szerokości)
    jpg/   raster na tle (biel; negatyw na błękicie #2C63C2)
  ksiega-znaku.pdf   (dodać po eksporcie)
```

Nazwy plików: `impuls-{wersja}-{kolor}`

- wersja: `sygnet`, `poziomy` (podstawowa), `poziomy-haslo`, `pionowy`
- kolor: `kolor`, `negatyw` (biały – na błękicie lub granacie), `achromatyczny`, `mono` (czarny)

Każdy plik zawiera pole ochronne x = ¼ wysokości sygnetu.
